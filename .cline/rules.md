# Cline Development Rules for Converge Marketing

## Development Server Rules
- Never run `npm run dev`, `yarn dev`, or similar development server commands
- User will manually test and QA all changes
- Focus on code implementation and completion rather than testing
- Do not use browser_action tool unless explicitly requested

## General Development Preferences
- Prioritize clean, maintainable code
- Follow existing project patterns and conventions
- Complete implementation before suggesting testing
- User handles all manual testing and quality assurance
